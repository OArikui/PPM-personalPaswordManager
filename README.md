# Personal Password Manager

Python + PyQt6 で動作する、個人利用向けのローカル型パスワードマネージャーです。

**Version: 1.3.0**

## 主な機能

### アカウント表示・検索
- サイト・サービス別、メールアドレス別、ユーザー名別のグループ表示
- 全項目横断検索
- 一覧からアカウントを選択して詳細表示
- パスワードや秘密情報を伏せた詳細表示と、表示/非表示の切り替え

### 基本項目とカスタム項目
- 基本項目: サイト・サービス名 / メールアドレス / パスワード / ユーザー名
- 任意のカスタム項目を追加・削除
- 項目名と値の入力候補に、過去の登録内容と変更履歴を利用
- カスタム項目は保管庫へ永続保存

### パスワード
- 暗号学的に安全な乱数によるパスワード生成
- 長さ、英大文字、英小文字、数字、記号を指定
- 選択アカウントのパスワードをクリップボードへコピー
- コピーから20秒後、クリップボードの内容が同じ場合に自動消去

### 変更履歴
- アカウントを編集する直前の状態をアカウント単位で保存
- 日時、操作種別、基本項目、カスタム項目を保存
- 履歴の閲覧と選択した状態への復元
- 復元前の状態も履歴へ保存
- 1アカウントあたり最大200世代

### バックアップ
- 暗号化された保管庫を .pwm ファイルとしてバックアップ
- バックアップファイルも暗号化状態を維持
- 復元前に現在の保管庫を別ファイルへ自動退避
- 同じ保管庫の鍵で復号できることを確認してから復元

### 保管庫・セキュリティ
- マスターパスワードから Scrypt で暗号鍵を導出
- 保管庫本体を Fernet で暗号化
- マスターパスワードそのものはファイルへ保存しない
- 一時ファイルへ書き込んでから置き換える方式で保存
- 手動ロックと15分間操作がない場合の自動ロック
- 旧形式(v1)の保管庫を読み込み、v2へ自動移行

### バックグラウンド・通知領域
- Windowsの通知領域（システムトレイ）にアイコンを表示
- トレイアイコンを左クリックするとメイン画面を表示
- ウィンドウの閉じるボタンを押すと終了せず、通知領域へ格納
- トレイアイコンの右クリックメニューからアカウント追加、検索、UI表示、保管庫ロック、終了を実行
- 15分間操作がない場合は保管庫をロックし、次回表示時にマスターパスワードを要求
- システムトレイが利用できない環境では通常ウィンドウで起動

### 保存先
- 初期保存先は Windows では %APPDATA%\PersonalPasswordManager\vault.pwm
- GUIの「保存先」から暗号化保管庫の場所を変更可能
- USBメモリなど任意のパスを指定可能
- 新しい場所へコピーし、暗号化データを検証してから保存先設定を更新
- 旧ファイルは自動削除せず残す

## 起動方法

Python 3.11 以上を推奨します。GUIには PyQt6 を使用します。

### Windows（推奨）

run.bat を実行してください。初回は .venv を作成し、必要なパッケージをインストールしてから起動します。

    .\run.bat

バックグラウンドで起動する場合（マスターパスワード認証後はメイン画面を表示せず、通知領域に常駐）:

    .\run.bat --background

バックグラウンド起動では Windows のコンソール画面を表示しない pythonw.exe を使用します。通知領域アイコンを右クリックして「終了」を選ぶまで常駐します。

特定の保管庫を指定する場合:

    .\run.bat --vault "E:\PasswordManager\my_vault.pwm"

従来の lunch.bat も run.bat を呼び出す互換ランチャーとして残しています。通知領域のアイコンを左クリックすると画面を開き、右クリックするとクイックアクションを表示します。ウィンドウの閉じるボタンでは終了せず、通知領域へ格納されます。アプリを完全に終了する場合は、通知領域アイコンの右クリックメニューから「終了」を選択してください。

### 手動で起動する場合

    python -m pip install -r requirements.txt
    python password_manager.py

Windows:

    py -m pip install -r requirements.txt
    py password_manager.py

## 初回起動

1. マスターパスワードを設定します（10文字以上を推奨）。
2. 保管庫が作成されます。
3. 「新規」からアカウントを登録します。
4. 「カスタム項目」タブから必要な項目を追加します。
5. 「バックアップ」から暗号化バックアップを作成できます。

## 旧版データについて

以前の v1 保管庫は、カスタム項目を維持したまま読み込めます。v1には変更履歴がないため、履歴は空の状態で開始し、編集した時点から履歴が記録されます。保管庫のデータ形式はv2のままで、今回のGUI変更によるデータ移行は必要ありません。

## 注意

これは個人利用向けのローカルアプリです。OSや実行環境が侵害された場合、メモリ上の秘密情報やクリップボードまで保護するものではありません。マスターパスワードを忘れた場合の復旧機能はありません。保管庫ファイルのバックアップと、復元手順のテストを行ってください。
