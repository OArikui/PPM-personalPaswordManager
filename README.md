# Personal Password Manager

Python + Tkinter で動作する、自分専用のローカル型パスワードマネージャーです。

## 実装済み機能

### アカウント表示・検索
- 「サイト・サービス別」「メールアドレス別」「ユーザー名別」の3種類でグループ表示
- 全項目横断検索
- アカウントを一覧から選択して詳細表示
- 詳細の表示/非表示切り替え

### 基本項目とカスタム項目
- 基本項目: サイト・サービス名 / メールアドレス / パスワード / ユーザー名
- 任意のカスタム項目を追加・削除
- カスタム項目名を過去の登録内容から候補表示
- **カスタム項目の値**も、同じ項目名の過去の現在値・変更履歴から候補表示
- 基本4項目の値も過去の現在値・変更履歴から候補表示
- カスタム項目は保管庫へ永続保存され、再起動後も消えません

### パスワード
- ランダムパスワード生成
- 長さ、英大文字、英小文字、数字、記号を指定
- 選択アカウントのパスワードをクリップボードへコピー
- コピー後20秒で、クリップボードの内容が同じであれば自動消去

### 変更履歴
- アカウントを編集する直前の状態を、アカウント単位で保存
- 履歴には日時、操作種別、全基本項目、全カスタム項目を保存
- 履歴一覧から過去の状態を閲覧
- 履歴から選択した状態への**復元機能**を搭載
- 復元前の現状態も「復元前」として新たに履歴へ保存
- 1アカウントあたり最大200世代

### バックアップ
- GUIの「💾 バックアップ」から、暗号化された保管庫を `.pwm` ファイルとしてコピー
- GUIの「↩ バックアップ復元」から、バックアップの内容を検証して復元
- 復元するバックアップが、現在開いている保管庫と同じ暗号鍵で復号できることを確認
- 復元直前の保管庫は、同じフォルダーへ `*.before-restore-*.pwm` として自動退避
- バックアップファイルも暗号化されたまま。復元時には元の保管庫のマスターパスワードが必要

### 保管庫・セキュリティ
- マスターパスワードから Scrypt で暗号鍵を導出
- 保管庫本体を Fernet で暗号化
- マスターパスワードそのものはファイルへ保存しない
- 保存は一時ファイルへ書き込み後に置換する方式
- 手動ロック
- 15分間操作がない場合の自動ロック
- 旧形式(v1)の保管庫を読み込み、v2へ自動移行可能

### 保存先
- 初期保存先は Windows では `%APPDATA%\\PersonalPasswordManager\\vault.pwm`
- GUIの「📁 保存先」から暗号化保管庫の場所を変更可能
- USBメモリなど任意のパスを指定可能
- 新しい場所へコピー後、暗号化データの復号確認をしてから保存先設定を更新
- 旧ファイルは自動削除せずバックアップとして残す
- 現在の保管庫パスは `%APPDATA%\\PersonalPasswordManager\\settings.json` に保存
- settings.json には保管庫パスだけを保存し、秘密情報は保存しない

## 起動方法

Python 3.11 以上を推奨します。Tkinter が使える Python を用意してください。

```bash
python -m pip install -r requirements.txt
python password_manager.py
```

Windows の PowerShell なら:

```powershell
py -m pip install -r requirements.txt
py password_manager.py
```

特定の保管庫を明示して起動する場合:

```bash
python password_manager.py --vault /path/to/vault.pwm
```

Windows:

```powershell
py password_manager.py --vault "E:\\PasswordManager\\my_vault.pwm"
```

## 初回起動

1. マスターパスワードを設定します。
2. 保管庫が作成されます。
3. 「＋ 新規」からアカウントを登録します。
4. 「＋ 項目を追加」でカスタム項目を追加します。
5. 次回から、既存の項目名や値が候補として表示されます。
6. 「💾 バックアップ」で暗号化バックアップを任意の場所に作成できます。復元するときは「↩ バックアップ復元」を選択してください。

## 旧版データについて

以前の v1 保管庫は、カスタム項目を維持したまま読み込めます。v1には変更履歴が存在しないため、履歴は空の状態で開始し、編集した時点から履歴が記録されます。

## 注意

これは個人利用向けのローカルアプリです。OSや実行環境が侵害された場合、メモリ上の秘密情報やクリップボードまで保護するものではありません。マスターパスワードを忘れた場合の復旧機能はありません。保管庫ファイルのバックアップと、復元手順のテストを行ってください。
